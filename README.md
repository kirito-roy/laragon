# LaraDock
<img src="./20250919_1846_Docker Laragon Blend_remix_01k5h1sy7cfaps9576ttv4ve7h.png">
A Docker-based local development environment similar to Laragon.

Created by **kirito roy**.

## Features
- Multiple PHP versions (PHP 8.2, 8.4, and 8.5)
- Auto SSL/HTTPS setup with `mkcert`
- Database containers included (PostgreSQL and Redis active by default, MySQL/Mongo available)
- Dynamic Nginx routing based on configuration
- Easy frontend asset management via Node container (optional)

## Folder Structure

Here is the current directory layout for this project:

```text
Laragon/
├── projects/            # Add all your project folders here
├── postgres_data/       # Auto-generated by Docker for PostgreSQL data persistence
├── postgres-init/       # Optional init scripts for PostgreSQL
├── nginx/               # Auto-generated by Docker (contains sites-enabled & ssl certs)
├── mkcert-ca/           # Auto-generated CA for local HTTPS support
├── .gitignore
├── docker-compose.yml   # Docker Compose services configuration
├── Dockerfile.php       # PHP 8.2 FPM image
├── Dockerfile.php-84    # PHP 8.4 FPM image
├── Dockerfile.php-85    # PHP 8.5 FPM image
├── Dockerfile.setup     # Setup container for generating Nginx configs & SSL certs
├── auto-setup.sh        # Setup script run by the setup container
├── sites.txt            # Your active sites and PHP version mapping
└── README.md
```

## User Manual

### 1. Project Setup Instructions

1. **Add your project**: Simply clone or place your project folder directly into the `projects` directory.
   *(Note: The entire `projects` folder is already mapped to the containers, so new projects are instantly available without editing `docker-compose.yml`!)*
2. **Configure Database**: Setup your database user and password in your project's `.env` file (e.g., `postgres` database server is available at `postgres:5432` with username `postgres` and password `root`).
3. **Register Site**: Add your site URL and desired PHP version mapping to `sites.txt`. Use `https` to take advantage of the auto-generated SSL certificates!
   We use the `.test` domain suffix for local projects.
   
   ```text
   https://project_folder_name.test(php-82)
   https://another_project.test(php-85)
   ```

4. **Map Domains in Hosts File**: Since `.test` domains do not automatically resolve on your host machine, you must map each registered domain to your local loopback address (`127.0.0.1`).
   
   Open your terminal on your host Linux system and run:
   ```bash
   sudo nano /etc/hosts
   ```
   Add the domain mappings at the end of the file:
   ```text
   127.0.0.1    project_folder_name.test
   127.0.0.1    another_project.test
   ```
   *(Or run this quick command: `sudo bash -c "echo '127.0.0.1 project_folder_name.test' >> /etc/hosts"`)*

### 2. Starting the Environment

Run the following command in the root folder:

```bash
docker compose up -d
```
*Note: The `setup` container will run automatically, parse your entries in `sites.txt`, clean up old configurations, and generate new Nginx virtual host files and trusted SSL certificates for you.*

### 3. Running Composer and NPM

**Composer (PHP Dependencies)**
```bash
docker compose exec php-82 sh   # Or php-84 / php-85
/var/www/html $ cd project_folder_name
/var/www/html/project_folder_name $ composer install
```
Press `Ctrl+D` to exit the container.

**NPM (Frontend Assets)**
If you uncomment the `node` service in `docker-compose.yml`:
```bash
docker compose exec node sh
/var/www/html # cd project_folder_name
/var/www/html/project_folder_name # npm install
/var/www/html/project_folder_name # npm run dev
```

### 4. Open in Browser

Visit your secure local site directly in your browser:

```
https://project_folder_name.test
```
